# Nicola Bellomo — Personal Website

Source files of Nicola Bellomo's academic website (gravitational-wave cosmology, University of Padova / INFN).

- **Publishing it for the first time / connecting a domain:** see [`PUBLISHING.md`](PUBLISHING.md)
- **Updating content (bio, news, papers, blog posts, CV):** see [`EDITING.md`](EDITING.md)

Every change pushed to the `main` branch is rebuilt and republished automatically by the
"Deploy site" GitHub Action (`.github/workflows/deploy.yml`), usually within 3 minutes.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT license, see `LICENSE`).
Technical documentation for the theme is in the [`docs/`](docs/) folder.
